# &lt; SQL Lesson 1: SELECT queries 101 &gt;

---

* SQL 데이터베이스에서 데이터를 추출하려면, SELECT 구문을 사용해야 함.
* SELECT 구문을 사용하는 형태를 '쿼리(query)'라고 함.
* 쿼리는 우리가 찾는 데이터가 무엇인지, 그 데이터를 데이터베이스 내에서 어디서 찾아야 하는지, 그 데이터를 가져오기 전에 어떻게 변환해야 하는지를 암시하는 구문.
* 특정 구문 형식이 정해져 있어, 이를 연습해야 함.
* 테이블의 열(column)은 해당 entity의 모든 instance가 공유하는 공통 속성을 나타냄.
* 일반적인 쿼리의 결과는, 행과 열의 집합으로 이루어진 2차원 집합임.
* `SELECT *`를 사용해서 테이블 내의 모든 열의 데이터를 불러올 수 있음.
